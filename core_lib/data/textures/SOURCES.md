# Paper grain textures

Licence: CC0 1.0 Universal (public domain), https://creativecommons.org/publicdomain/zero/1.0/
Source: ambientCG, https://ambientcg.com/ (all assets there are CC0).

Each file is the Displacement map of the ambientCG material (1K-JPG), centre-cropped to a
square, downscaled to 256x256, stretched to the full 0..255 range (1st to 99th percentile)
and saved as 8-bit grayscale PNG.

| File | Grain texture name | ambientCG asset |
|---|---|---|
| paper-1.png | Fine paper | https://ambientcg.com/view?id=Paper001 |
| paper-2.png | Crumpled | https://ambientcg.com/view?id=Paper003 |
| paper-3.png | Laid paper | https://ambientcg.com/view?id=Paper004 |
| paper-4.png | Creased | https://ambientcg.com/view?id=Paper005 |
| paper-5.png | Mottled | https://ambientcg.com/view?id=Paper006 |

Texture 0, "Generated", is code in `tiledbuffer.cpp`, not a file.
