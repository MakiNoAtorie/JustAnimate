# Shortcut presets for other apps

JustAnimate ships one default shortcut set. It does not ship presets that copy Pencil2D, Krita or Toon Boom shortcuts.

## Why this is out of scope

Every shortcut is configurable, and a shortcut set can be exported and imported from Preferences. A preset per app has to be researched and kept correct as those apps change, and nobody has asked for one. The lean rules build a feature only when someone needs it.

If users ask for a specific app's set, it can ship as an importable shortcut file rather than new code.
