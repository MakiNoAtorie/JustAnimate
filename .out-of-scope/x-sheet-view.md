# X-sheet view

JustAnimate has no exposure-sheet (X-sheet) view of the timeline.

## Why this is out of scope

The timeline already shows every layer's keys and holds. An X-sheet is a second, vertical view of the same data for a traditional workflow; it needs its own widget, editing rules and sync with the timeline (roadmap item 3.9, size L). The lean rules build a feature only when someone needs it, and nobody has asked for this one.

If users ask for it, reopen the idea with their workflow as the spec.
